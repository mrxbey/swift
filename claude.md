# Claude Code Skills - HabitTracker

This project uses Claude Code Skills for consistent development workflows.

## Available Skills

### 🎯 Meta Skills
- **skill-creator** - Creates new Claude Code Skills with best practices

### 🔧 Development Skills
- **supabase-integration** - Supabase backend integration, repositories, RLS, RPCs
- **tca-development** - The Composable Architecture (TCA 1.23.1) patterns
- **swiftui-best-practices** - Modern SwiftUI (iOS 17+) implementation

## Usage

Skills activate automatically when you mention relevant keywords. See individual SKILL.md files for trigger words and usage.

**Location:** `.claude/skills/*/SKILL.md`

## Creating New Skills

Use the `skill-creator` skill to generate new project-specific skills:
- "Create a skill for testing"
- "Create a skill for database migrations"
- "Create a skill for analytics"
